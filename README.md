# Simple Interest Calculator

This project contains a simple interest calculator.

## Formula

Simple Interest = (P × T × R) / 100

Where:
- P = Principal amount
- T = Time period
- R = Rate of interest

## Features
- Calculates simple interest
- Easy to use
- Written in Bash
